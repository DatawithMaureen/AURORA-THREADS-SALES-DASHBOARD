# AURORA THREADS SALES DASHBOARD

## Project Overview

This project is an interactive retail sales dashboard built in Power BI to analyze customer behavior, revenue trends, product performance, and payment patterns for Aurora Threads.

The dashboard provides business insights into sales distribution, customer purchases, revenue generation, and product demand using dynamic visualizations and interactive filters.


## Objectives

The purpose of this project was to:

- Analyze retail sales performance
- Track revenue generation across products and categories
- Monitor customer purchasing behavior
- Identify top-performing products
- Explore payment method trends
- Build an interactive and visually appealing Power BI dashboard


## Dashboard KPIs

The dashboard tracks key retail metrics including:

- Total Revenue: $24K
- Total Customers
- Number of Stores
- Total Quantity
  

## Key Insights

### Revenue Analysis
- Accessories generated the highest revenue among all product categories.
- Handbags recorded the highest product revenue contribution.
- Revenue distribution varied across different product types.

### Customer Insights
- Female customers contributed the largest share of revenue.
- Customer purchasing behavior varied across product categories.

### Payment Analysis
- Cash payments generated the highest transaction value.
- Online payment and card payment usage were comparatively lower.

### Product Performance
- Fashion accessories and wearable products performed strongly in sales.
- Revenue concentration was highest among a few top-selling products.
